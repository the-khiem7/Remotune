One CRD session

Remotune tunes Windows while you are connected, then puts it back

1

Before CRD

Your state

Windows stays exactly as you left it. Remotune only watches for CRD connect and disconnect events.

2

CRD connects

Tuning: Active
  1. Save a snapshot of your Visual Effects and taskbar auto-hide to disk
  2. Apply your CRD ON profile
  3. Turn taskbar auto-hide off so the remote taskbar stays visible
3

CRD disconnects

Tuning: Baseline
  1. Visual Effects follow your CRD OFF choice
  2. Taskbar auto-hide returns to its saved state
  3. The snapshot is retired once Windows is verified
!

If an apply or restore cannot be verified, Remotune shows Partial/Error and keeps the snapshot, so Restore Now can retry. With no Remotune-owned snapshot, Restore Now restores nothing.

Who owns the current Windows state

Applying starts when CRD connects, or when automation resumes while connected.

Restoring starts when CRD disconnects, or on Pause, Restore Now or Quit.

Partial/Error

An apply or restore did not verify. The snapshot is kept and Restore Now can retry.

Recovery Required

Recovery data could not be read or retired, so it needs attention.

Valid combination: CRD Connected, Automation Paused and Tuning Baseline. A session exists, but Remotune is not tuning it.
